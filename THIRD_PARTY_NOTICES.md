# Third-party data

## Oliveira API-call sequences (CC BY 4.0)

A. Oliveira, "Malware Analysis Datasets: API Call Sequences", Kaggle (ang3loliveira) and IEEE DataPort,
doi:10.21227/tqqm-aq14. Licence: Creative Commons Attribution 4.0 International (https://creativecommons.org/licenses/by/4.0/).
Associated publication: A. Oliveira and R. J. Sassi, "Behavioral Malware Detection Using Deep Graph Convolutional Neural
Networks", TechRxiv, 2019, doi:10.36227/techrxiv.10043099.v1.

Derived files in this repository: `revision_step1_audit/*.csv`, `revision_step2/*.csv`, `results_v4/dedup_splits.npz`.
Changes: exact duplicates removed, label-conflict and mixed-label components excluded, split assignment added.

## MalAPI-2019 sample (MIT)

`sample_analysis_data.txt` contains 100 sequences from the MalAPI-2019 dataset
(https://github.com/ocatak/malware_api_class; F. O. Catak, A. F. Yazi, O. Elezaj and J. Ahmed, "Deep learning based
sequential model for malware analysis using Windows exe API calls", PeerJ Computer Science 6:e285, 2020).
